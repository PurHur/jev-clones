What this means for Zeiger

From COMPARISON.md §10.

  1. Keep chunked long context and the option set module. No other clone handles pages with more than 255 elements.
  2. Move to a shared state cache, one row per question. Qwen3-0.6B is pure attention, so a KV fork or kev's block-causal mask works without DeltaNet complications.
  3. Test order bias cheaply. Drop positions in the set module (ejhshen/OpenJev) or average two option orders (Xor).
  4. Richer calibration. Per-type temperatures (Strands) or input-dependent ones (Von) next to our option-count buckets; basal's certified thresholds fit the jevpilot action gate.
  5. From WebJev: jev-ultrafast's wire format and 125-task live benchmark, a separate operation/DONE question, richer element fields, hard negatives.
  6. CPU tier: Crivo-150M's distillation recipe and Decima's order-free, linear-cost scoring.
  7. Stay clean: no Jev-distilled data and no benchmark train splits.
