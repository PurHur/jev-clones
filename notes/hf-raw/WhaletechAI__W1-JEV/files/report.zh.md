# 蓝色鲸鱼 W1-JEV

### 毫秒级判断，千次 GPU 成本不到 1 美分。

**33 ms 中位延迟 · $0.00567 / 千次请求 · 一秒处理30封邮件**

[English model card](./README.md)

蓝色鲸鱼 W1-JEV 是基于我们自研 **W1 DLM** 构建的 **4B 级结构化判断模型**。我们通过后训练对齐输出格式，复现 JEV 的判断任务，面向判断与高频自动化处理场景。

在 **231 道匹配的公开适配题目**上，W1-JEV 答对 **184 道**，达到 Jev 1.13.0 公开记录中 **92% 的准确率水平**。按发布方测算，GPU 占用成本约为参考方案的 **1/7**。

本次测试用 **10.8373 秒**完成全部 231 次请求，严格格式合法率为 **100%**。按 $0.435/GPU-hour 计价，每 1,000 次请求的 GPU 占用成本仅为 **$0.00567，约合 0.57 美分**。

![W1-JEV 与 Jev 1.13.0 对比](./assets/w1-jev-comparison.zh.png)

## 为高频判断而设计

当每条输入都需要经过一次判断，单次请求的耗时和成本就会不断累积。W1-JEV 聚焦这一重复执行的环节，让批量判断更快、更经济。

- **快速返回判断。** 本次测试的端到端请求延迟 p50 为 **33.13 ms**，整体吞吐量为 **每秒 21.32 次请求**。
- **降低单次 GPU 成本。** 在上述计价口径下，每 1,000 次请求的 GPU 占用成本为 **$0.00567**。
- **输出符合流程要求。** 本次 **231 次请求全部完成**，输出全部通过严格格式校验。
- **支持本地部署。** 发布文件包含纯 PyTorch 模型、W1 专用运行时、本地 HTTP 服务与可执行的选择题客户端。

## 准确率：达到参考结果的 92%

以下结果来自公开适配集中 **231 道匹配的题目**。W1-JEV 为发布方报告结果；Jev 1.13.0 为公开记录结果。

| 指标 | W1-JEV（发布方报告） | Jev 1.13.0（公开记录） |
| --- | ---: | ---: |
| 匹配题目答对数 | **184 / 231** | 200 / 231 |
| 原始准确率 | **79.65%** | 86.58% |
| 简单子集答对数 | **48 / 48** | 48 / 48 |

W1-JEV 在简单子集上与参考结果一致，全部答对；在完整匹配题集上，少答对 16 道题，准确率相差 **6.93 个百分点**。

**92% 指准确率的相对比例**：`(184 / 231) ÷ (200 / 231) = 92%`。W1-JEV 的绝对准确率为 **79.65%**；这一比例仅描述当前题集上的对比结果。

## 性能与 GPU 成本

本次测试使用单张 **NVIDIA GeForce RTX 5090**，配置为 **2 路客户端并发**、单 GPU worker、**最大 batch 2**；共 116 批，平均 batch 1.99，最长等批 5 ms。

| 指标 | 报告结果 |
| --- | ---: |
| 端到端请求延迟 p50 / p95 | **33.13 / 374.02 ms** |
| 吞吐量 | **21.32 次请求/秒** |
| 总墙钟耗时 | **10.8373 秒** |
| 已完成请求 | **231 / 231** |
| 严格格式合法率 | **100%** |
| PyTorch 峰值已分配显存 | **7.45 GiB** |
| GPU 计价 | **$0.435 / GPU-hour** |
| 每 1,000 次请求的 GPU 占用成本 | **$0.00567** |

成本按本次运行时长分摊计算：

```text
每千次请求 GPU 占用成本
= 10.8373 秒 ÷ 3600 × $0.435 ÷ 231 × 1000
≈ $0.00567
```

该数值为分摊到本次运行的 GPU 占用成本，不包含其他服务开销，也不是托管 API 售价。7.45 GiB 为 PyTorch 峰值已分配显存，不等于完整部署所需的总显存。

## 模型架构

W1-JEV 使用自定义的纯 PyTorch **`LangDiT` 语言扩散 Transformer**，采用双向注意力、时间步条件与自适应层归一化。

| 属性 | 配置 |
| --- | --- |
| 模型实现 | 自定义 PyTorch `LangDiT` |
| 参数量 | **3,739,097,600，约 3.74B，属于 4B 级模型** |
| Transformer 层数 | 48 |
| 词表大小 | 64,512 |
| 隐藏层 / 注意力 / FFN 维度 | 2,048 / 3,072 / 7,168 |
| 注意力头数 / 每头维度 | 24 / 128 |
| 注意力机制 | 双向注意力、RoPE、无因果掩码 |
| 条件机制 | 时间步嵌入与自适应层归一化 |
| 默认运行时输入上限 | **4,096 tokens**，可通过 `model.max_seq_len` 配置 |
| 默认推理精度 | **BF16** |

模型权重文件以 **FP32** 保存，默认使用 **BF16** 推理。运行时输入上限由 `config.json` 中的 `model.max_seq_len` 配置；RoPE 按实际序列长度动态计算。

## 运行入口

推理使用仓库提供的 W1 专用运行时，主要入口如下：

- **`structured_server.py`**：W1 运行时与本地 HTTP 服务。
- **`examples/ask.py`**：可执行的选择题请求客户端。
- **`config.json`**：模型架构与运行时上下文配置。

## 仓库文件说明

| 文件 | 用途 |
| --- | --- |

| `djev_template.py` | 提取的 djev schema、提示词、模板与调度辅助函数。 |
| `structured_server.py` | W1 专用运行时与本地 HTTP 服务。 |
| `examples/ask.py` | 可执行的选择题请求客户端。 |
| `README.md` | 英文 model card。 |
| `report.zh.md` | 中文模型介绍、评测报告与仓库说明。 |
