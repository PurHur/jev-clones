# System 1 adapter (PEFT LoRA)

LoRA adapter for [google/gemma-4-26B-A4B-it](https://huggingface.co/google/gemma-4-26B-A4B-it), part of
[autotrust/GEV-26B-Decide](https://huggingface.co/autotrust/GEV-26B-Decide). Use it with `head.safetensors`, `judge_config.json`
and `calibration.json` from the repository root; see the model card. `adapter_vllm/` is the same System 1 for vLLM.
