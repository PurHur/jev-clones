# Bespoke-Nimble-27B-v3

Bespoke-Nimble-27B-v3 is a decision model made by [Bespoke Labs](https://bespokelabs.ai). Given a context and typed questions (a choice among options, or yes or no), it returns a probability for each option.

Decision Index 0.3, public suite: 65.33. The full run is in [bespokelabs/bespoke-nimble-27b-v3-decision-index](https://huggingface.co/datasets/bespokelabs/bespoke-nimble-27b-v3-decision-index).

## Weights

The weights are not released yet. `PLACEHOLDER_WEIGHTS.md` holds their place; this repository has no model files. The model runs on Bespoke Labs' hosted API. For access, contact [Bespoke Labs](https://bespokelabs.ai).
