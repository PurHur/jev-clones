+# Clef
+
+Clef is a decision head that scores all the options of all the questions of a request jointly. It was introduced by [Cloudflare/clef](https://huggingface.co/Cloudflare/clef) and is also used by [Cloudflare/clef-flash](https://huggingface.co/Cloudflare/clef-flash). The template marks the span of each instruction and of each of its options. The options of all the questions are packed in one sequence: pooled from the hidden states and from the output embeddings of their tokens, they attend to the prompt and are summarized into the field of their question. The fields then attend to each other and to the prompt, and each option is scored against the field of its question. The original `joint_head.safetensors` loads as is.
+
+Decision heads are applied by [`DecisionPipeline`] to the hidden states of the original checkpoint. The chat template,
+the settings and the head live in their own repo next to it.
+
+```python
+from transformers import pipeline
+
+decide = pipeline("decision", model="Cloudflare/clef-flash", decision_config="ArthurZ/clef-flash")
+decide(
+    {
+        "state": "I was charged twice for my order and want a refund.",
+        "questions": {
+            "refund": {"type": "noul", "instructions": "Is a refund requested?"},
+            "topic": {"type": "choice", "instructions": "What is it about?", "criteria": {"billing": None, "shipping": None}},
+        },
+    }
+)
+```

+# JEV
+
+JEV is a decision head that scores single-token labels with a linear layer at the last token of the prompt, soft-capped like the logits of a language model head. It was introduced by [JEV](https://huggingface.co/autotrust/JEV-9B) and is also used by [GEV](https://huggingface.co/autotrust/GEV-26B-Decide).
+
+Decision heads are applied by [`DecisionPipeline`] to the hidden states of the original checkpoint. The chat template,
+the settings and the head live in their own repo next to it.
+
+```python
+from transformers import pipeline
+
+decide = pipeline("decision", model="autotrust/GEV-26B-Decide", decision_config="ArthurZ/GEV-26B-Decide")
+decide(
+    {
+        "state": "I was charged twice for my order and want a refund.",
+        "questions": {"refund": {"type": "noul", "instructions": "Is a refund requested?"}},
+    }
+)
+decide("Where is my parcel?")  # a bare state is asked the questions of the last request
+```
+
+Questions can also be set when creating the pipeline, or per call, and become the ones asked of the next bare states:
+
+```python
+decide = pipeline(
+    "decision",
+    model="autotrust/GEV-26B-Decide",
+    decision_config="ArthurZ/GEV-26B-Decide",
+    questions={"refund": {"type": "noul", "instructions": "Is a refund requested?"}},
+)
+decide("I was charged twice for my order and want a refund.")
+decide("Buy cheap watches now!!!", questions={"spam": {"type": "noul", "instructions": "Is this spam?"}})
+```
+
+Images come as `assets`, like in the System One API: each placeholder in the state, the instructions or the criteria is
+replaced with its image. An asset is `{"type": "image", "format": "png", "data_base64": ...}`, a PIL image, a path or a
+URL, and the model needs a processor that handles images.
+
+```python
+decide(
+    {
+        "state": "The customer sent photo-1 and asks if it is damaged.",
+        "assets": {"photo-1": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/coco_sample.png"},
+        "questions": {"damaged": {"type": "noul", "instructions": "Is the product in the photo damaged?"}},
+    }
+)
+```
+
+The same head reads the 255 answer codes of [pplx-decider](https://huggingface.co/perplexity-ai/pplx-decider-v1.1-27b)
+and [d3](https://huggingface.co/vllm-sr/d3), whose Qwen3.5 backbone attends to the whole prompt
+(`use_bidirectional_attention`). `convert_decider_to_hf.py` writes their head, which loads the backbone from the
+original repo:
+
+```python
+pplx = pipeline("decision", model="ArthurZ/pplx-decider-v1.1-27b")
+d3 = pipeline("decision", model="ArthurZ/d3")
+request = {
+    "state": "I was charged twice for my order and I want my money back today.",
+    "questions": {
+        "refund": {"type": "noul", "instructions": "Does the customer ask for a refund?"},
+        "urgency": {"type": "score", "criteria": ["Can wait", "This week", "Today", "Now"]},
+    },
+}
+pplx(request), d3(request)
+```

+# von
+
+von is an option marker decision head introduced by [von](https://huggingface.co/wfzyx/von): an MLP scores each option from the hidden state of the `[MASK]` token in front of it. Options only attend to the prompt and to themselves, at positions that restart after the prompt, with masks built by the [masking API](../attention_interface#build-an-attention-mask) for `sdpa`, `eager` and `flex_attention`. The scores of a zero-shot `noul` question are debiased by the same question asked without the state.
+
+Decision heads are applied by [`DecisionPipeline`] to the hidden states of the original checkpoint. The chat template,
+the settings and the head live in their own repo next to it.
+
+```python
+from transformers import pipeline
+
+decide = pipeline("decision", model="wfzyx/von", decision_config="ArthurZ/von")
+decide(
+    {
+        "state": "I was charged twice for my order and want a refund.",
+        "questions": {"refund": {"type": "noul", "instructions": "Is a refund requested?"}},
+    }
+)
+```

+def parse_questions(questions: dict[str, Any], config: DecisionConfig) -> list[Question]:
+    """
+    Validates the `questions` of a System One request and puts them in template order, raising one `ValueError` that
+    lists every invalid question, each with an example of a valid one.
+    """
+    if not isinstance(questions, dict) or not questions:
+        raise ValueError(f"`questions` maps names to questions, with at least one question; got {questions!r}.")
+    parsed, errors = [], []
+    for name, question in questions.items():
+        try:
+            parsed.append(Question.from_request(name, question, config))
+        except ValueError as error:
+            errors.append(str(error))
+    if errors:
+        raise ValueError("\n".join(errors))
+    return parsed
+

+def _split_at_placeholders(text: str, assets: dict[str, Any], load) -> list[dict[str, Any]]:
+    """The content blocks of `text`: its text, with an image block where a placeholder of `assets` is."""
+    if not assets:
+        return [{"type": "text", "text": text}]
+    pattern = re.compile("|".join(re.escape(name) for name in sorted(assets, key=len, reverse=True)))
+    content, last = [], 0
+    for match in pattern.finditer(text):
+        content += [{"type": "text", "text": text[last : match.start()]}, {"type": "image", "image": load(match[0])}]
+        last = match.end()
+    content.append({"type": "text", "text": text[last:]})
+    return [block for block in content if block.get("text") != ""]
+
+
+def _load_asset(asset: Any):
+    if isinstance(asset, dict):  # a System One asset
+        if asset.get("type") != "image" or "data_base64" not in asset:
+            raise ValueError(f"Assets are images with `data_base64`, got {sorted(asset)}.")
+        asset = f"data:image/{asset.get('format', 'png')};base64,{asset['data_base64']}"
+    return load_image(asset)
+

+def _image_parts(variables: dict[str, Any], assets: dict[str, Any], load) -> tuple[dict, dict, list]:
+    """
+    A copy of `variables` where each string with asset placeholders is a list of text and image parts, the same copy
+    with each image part as a `\0index\0` text part (to find the order the template renders the images in), and the
+    images.
+    """
+    variables, numbered, images = copy.deepcopy(variables), copy.deepcopy(variables), []
+    containers = [(variables, numbered)]
+    while containers:
+        container, numbered_container = containers.pop()
+        for key in list(container) if isinstance(container, dict) else range(len(container)):
+            value = container[key]
+            if isinstance(value, (dict, list)):
+                containers.append((value, numbered_container[key]))
+                continue
+            parts = _split_at_placeholders(value, assets, load) if isinstance(value, str) else []
+            if not any(part["type"] == "image" for part in parts):
+                continue
+            container[key], numbered_container[key] = parts, []
+            for part in parts:
+                if part["type"] == "image":
+                    images.append(part["image"])
+                    part = {"type": "text", "text": f"\0{len(images) - 1}\0"}
+                numbered_container[key].append(part)
+    return variables, numbered, images

+class DecisionTemplate:
+    """
+    Renders a System One request into [`DecisionPrompt`]s with `apply_chat_template`: one per question, or one for all
+    when the decision template uses `questions`. A decision template gets the request as `state` and `question` (or
+    `questions`), with the images of its `assets` as `{"type": "image", "image": ...}` parts of `state`, and writes
+    `<|mark|>` where a head reads and `<|split|>` where the prompt is tokenized in pieces. Without one, the generic
+    `DECISION_PROMPT` is the user message of the model's chat template, read after the generation prompt.
+
+    Args:
+        processor (`PreTrainedTokenizerBase` or `ProcessorMixin`):
+            The tokenizer, or the processor of models that see images.
+        config ([`DecisionConfig`], *optional*):
+            The settings of the decision model.
+        questions (`dict`, *optional*):
+            The questions asked when a call gets a bare state, until a request brings others.
+    """
+
+    def __init__(self, processor, config: DecisionConfig | None = None, questions: dict[str, Any] | None = None):
+        # A copy with the sentinels as special tokens: they split the text they're in, and requests can't write them
+        processor = copy.deepcopy(processor)
+        self.tokenizer = getattr(processor, "tokenizer", processor)
+        self.tokenizer.add_tokens([AddedToken(token, special=True, normalized=False) for token in (MARK, SPLIT)])
+        self.mark_id, self.split_id = self.tokenizer.convert_tokens_to_ids([MARK, SPLIT])
+        self.processor = processor if getattr(processor, "image_processor", None) is not None else None
+        self.config = config or DecisionConfig()
+        self.decision_template = self.config.chat_template
+        self.prompt = _compile_jinja_template(self.decision_template or DECISION_PROMPT)
+        self.variables = _get_template_variables(self.decision_template or DECISION_PROMPT)
+        self.one_prompt = "questions" in self.variables
+        self.chat_kwargs = {"enable_thinking": False}
+        if self.processor is not None and "enable_thinking" not in _get_template_variables(processor.chat_template):
+            self.chat_kwargs = {}  # processors pass the variables their template doesn't use to the processor
+        # Each distinct set of questions is validated once: keyed by its JSON, a repeated set is a cache hit
+        self._parse_questions = functools.lru_cache(maxsize=256)(
+            lambda questions: parse_questions(json.loads(questions), self.config)
+        )
+        # The questions asked when a call gets a bare state: the ones given here, then those of the last request
+        self.questions = None if questions is None else self.parse_questions(questions)
+        self.question_assets = {}
+
+    def parse_questions(self, questions: dict[str, Any]) -> list[Question]:
+        """[`parse_questions`], cached: the returned list is shared between calls and must not be modified."""
+        return self._parse_questions(json.dumps(questions, ensure_ascii=False))
+
+    def __call__(
+        self, request: dict[str, Any] | str | Any, assets: dict[str, Any] | None = None
+    ) -> list[DecisionPrompt]:
+        """
+        Answers a decision `request`: a `{"state": ..., "questions": ..., "assets": ...}` as a dict or a JSON.
+        The question is cached, this way you can pass only a `str` (a state) and it will re-use the question.
+
+        `assets` map placeholders to images, as in the System One API: each placeholder in a string of the state, the
+        instructions or the criteria is replaced with its image. An image is an asset (`{"type": "image", "format":
+        "png", "data_base64": ...}`), or anything [`~image_utils.load_image`] takes, like a PIL image, a path or a URL.
+        """
+        if isinstance(request, str):  # a request as JSON, parsed so that `\u` escapes can't hide control tokens
+            try:
+                parsed = json.loads(request)
+            except json.JSONDecodeError:
+                parsed = None
+            request = parsed if isinstance(parsed, dict) and "questions" in parsed else request
+        if not self.config.sanitize_control_tokens:  # templates that escape control tokens still get no sentinels
+            # images aren't JSON, and have no sentinels
+            request_assets = request.get("assets") if isinstance(request, dict) else None
+            request = {k: v for k, v in request.items() if k != "assets"} if request_assets is not None else request
+            request = json.loads(json.dumps(request, ensure_ascii=False).replace(MARK, "").replace(SPLIT, ""))
+            if request_assets is not None:
+                request["assets"] = request_assets
+        if isinstance(request, dict) and "questions" in request:
+            if "state" not in request:
+                raise ValueError(
+                    'A request is {"state": ..., "questions": {name: question, ...}}, `state` is missing.'
+                )
+            assets = {**request.get("assets", {}), **(assets or {})}
+            self.questions, state = self.parse_questions(request["questions"]), request["state"]
+            questions_text = json.dumps(request["questions"], ensure_ascii=False)
+            self.question_assets = {name: asset for name, asset in assets.items() if name in questions_text}
+        elif self.questions is None:
+            raise ValueError(
+                'No questions to ask yet: send {"state": ..., "questions": {...}} once, or set `questions` up front.'
+            )
+        else:
+            assets, state = {**self.question_assets, **(assets or {})}, request
+        if assets and self.processor is None:
+            raise ValueError("Images need a model whose processor handles them.")
+        load = functools.cache(lambda name: _load_asset(assets[name]))
+        sanitize = self.config.sanitize_control_tokens
+        prompts = []
+        for group in [self.questions] if self.one_prompt else [[question] for question in self.questions]:
+            if self.decision_template is None:
+                text = self.prompt.render(state=state, question=group[0])
+                content = _split_at_placeholders(text, assets, load) if self.processor is not None else text
+                kwargs = {"sanitize_control_tokens": sanitize}
+            else:
+                variables = {"state": state, "question": asdict(group[0]), "questions": [asdict(q) for q in group]}
+                variables = {name: value for name, value in variables.items() if name in self.variables}
+                images = []
+                if assets:
+                    variables, numbered, found = _image_parts(variables, assets, load)
+                    # The processor takes the images in the order the template renders them
+                    order = re.findall("\0(\\d+)\0", self.prompt.render(**numbered))
+                    images = [found[int(index)] for index in order]
+                content, kwargs = "", {"chat_template": self.decision_template, **variables}
+                kwargs["sanitize_control_tokens"] = list(variables) if sanitize else False
+                if images:
+                    kwargs["processor_kwargs"] = {"images": images}
+            inputs = (self.processor or self.tokenizer).apply_chat_template(
+                [{"role": "user", "content": content}],
+                add_generation_prompt=True,
+                tokenize=True,
+                return_dict=True,
+                return_tensors="pt",
+                **self.chat_kwargs,
+                **kwargs,
+            )
+            prompts.append(self._prompt(inputs, group))
+        return prompts
+
+    def _prompt(self, inputs: dict[str, Any], questions: list[Question]) -> DecisionPrompt:
+        """Drops the sentinels from the inputs: the marks are the number of tokens before each `<|mark|>`."""
+        ids = inputs["input_ids"][0]
+        token_to_keep = (ids != self.mark_id) & (ids != self.split_id)
+        marks = token_to_keep.cumsum(0)[ids == self.mark_id].tolist()
+        per_token = {
+            key: value[:, token_to_keep]
+            for key, value in inputs.items()
+            if getattr(value, "shape", ())[-1:] == ids.shape
+        }
+        tensors = {key: value for key, value in inputs.items() if key not in per_token}
+        input_ids = per_token.pop("input_ids")[0].tolist()
+        per_token.pop("attention_mask", None)
+        # The default prompt is read after the generation prompt
+        return DecisionPrompt(input_ids, marks or [len(input_ids)], questions, {**per_token, **tensors})
+

+class CalibratedTemperatureLogitsWarper(LogitsProcessor):
+    r"""
+    [`LogitsProcessor`] dividing the scores by an input-conditioned temperature
+    `clamp(bias + entropy * H + log_tokens * log10(n) / 4 + n_options * K / 8, lo, hi)`, with `H` the normalized entropy
+    of the scores, `n` the length of `input_ids` and `K` the size of the last dimension of the scores. Used by decision
+    models, on the option scores of a question.
+
+    Args:
+        lo (`float`):
+            Lowest temperature.
+        hi (`float`):
+            Highest temperature.
+        bias, entropy, log_tokens, n_options (`float`, *optional*, defaults to 0):
+            Weights of the features.
+    """
+
+    def __init__(
+        self,
+        lo: float,
+        hi: float,
+        bias: float = 0.0,
+        entropy: float = 0.0,
+        log_tokens: float = 0.0,
+        n_options: float = 0.0,
+    ):
+        self.lo, self.hi = lo, hi
+        self.bias, self.entropy, self.log_tokens, self.n_options = bias, entropy, log_tokens, n_options
+
+    @add_start_docstrings(LOGITS_PROCESSOR_INPUTS_DOCSTRING)
+    def __call__(self, input_ids: torch.LongTensor, scores: torch.FloatTensor) -> torch.FloatTensor:
+        n_options, probabilities = scores.shape[-1], scores.softmax(-1)
+        entropy = -(probabilities * probabilities.clamp_min(1e-12).log()).sum(-1, keepdim=True)
+        temperature = (
+            self.bias
+            + self.entropy * entropy / math.log(max(n_options, 2))
+            + self.log_tokens * math.log10(max(input_ids.shape[-1], 1)) / 4
+            + self.n_options * n_options / 8
+        )
+        return scores / temperature.clamp(self.lo, self.hi).clamp_min(1e-4)

+class NoulBandLogitsWarper(LogitsProcessor):
+    r"""
+    [`LogitsProcessor`] for the two scores of a yes/no question: keeps the probability `p` of `true` within a band,
+    `edge + slope * (p - 0.5)` above 0.5 and mirrored below. Returns log-probabilities. Used by decision models.
+
+    Args:
+        edge (`float`):
+            Probability of `true` at `p = 0.5`.
+        slope (`float`):
+            Slope of the band.
+        true_index (`int`, *optional*, defaults to 0):
+            Index of `true` in the last dimension of the scores.
+    """
+
+    def __init__(self, edge: float, slope: float, true_index: int = 0):
+        self.edge, self.slope, self.true_index = edge, slope, true_index
+
+    @add_start_docstrings(LOGITS_PROCESSOR_INPUTS_DOCSTRING)
+    def __call__(self, input_ids: torch.LongTensor, scores: torch.FloatTensor) -> torch.FloatTensor:
+        p_true = scores.softmax(-1)[..., self.true_index]
+        p_true = torch.where(
+            p_true >= 0.5, self.edge + self.slope * (p_true - 0.5), 1 - self.edge - self.slope * (0.5 - p_true)
+        ).clamp(0, 1)
+        probabilities = [p_true, 1 - p_true] if self.true_index == 0 else [1 - p_true, p_true]
+        return torch.stack(probabilities, -1).log()

+def repeat_kv(hidden_states: torch.Tensor, n_rep: int) -> torch.Tensor:
+    """
+    This is the equivalent of torch.repeat_interleave(x, dim=1, repeats=n_rep). The hidden states go from (batch,
+    num_key_value_heads, seqlen, head_dim) to (batch, num_attention_heads, seqlen, head_dim)
+    """
+    batch, num_key_value_heads, slen, head_dim = hidden_states.shape
+    if n_rep == 1:
+        return hidden_states
+    hidden_states = hidden_states[:, :, None, :, :].expand(batch, num_key_value_heads, n_rep, slen, head_dim)
+    return hidden_states.reshape(batch, num_key_value_heads * n_rep, slen, head_dim)
+

+def eager_attention_forward(
+    module: nn.Module,
+    query: torch.Tensor,
+    key: torch.Tensor,
+    value: torch.Tensor,
+    attention_mask: torch.Tensor | None,
+    scaling: float,
+    dropout: float = 0.0,
+    **kwargs: Unpack[TransformersKwargs],
+):
+    key_states = repeat_kv(key, module.num_key_value_groups)
+    value_states = repeat_kv(value, module.num_key_value_groups)
+
+    attn_weights = torch.matmul(query, key_states.transpose(2, 3)) * scaling
+    if attention_mask is not None:
+        attn_weights = attn_weights + attention_mask
+
+    attn_weights = nn.functional.softmax(attn_weights, dim=-1, dtype=torch.float32).to(query.dtype)
+    attn_weights = nn.functional.dropout(attn_weights, p=dropout, training=module.training)
+    attn_output = torch.matmul(attn_weights, value_states)
+    attn_output = attn_output.transpose(1, 2).contiguous()
+
+    return attn_output, attn_weights

+# Modular automatically inherits RoPE, hence no inheritance for now
+class ClefAttention(nn.Module):
+    def __init__(self, config: ClefConfig):
+        super().__init__()
+        self.config = config
+        self.head_dim = getattr(config, "head_dim", config.hidden_size // config.num_attention_heads)
+        self.num_key_value_groups = config.num_attention_heads // config.num_key_value_heads
+        self.scaling = self.head_dim**-0.5
+        self.attention_dropout = config.attention_dropout
+        self.is_causal = False
+        self.q_proj = nn.Linear(
+            config.hidden_size, config.num_attention_heads * self.head_dim, bias=config.attention_bias
+        )
+        self.k_proj = nn.Linear(
+            config.hidden_size, config.num_key_value_heads * self.head_dim, bias=config.attention_bias
+        )
+        self.v_proj = nn.Linear(
+            config.hidden_size, config.num_key_value_heads * self.head_dim, bias=config.attention_bias
+        )
+        self.o_proj = nn.Linear(
+            config.num_attention_heads * self.head_dim, config.hidden_size, bias=config.attention_bias
+        )
+
+    def forward(
+        self,
+        hidden_states: torch.Tensor,
+        encoder_hidden_states: torch.Tensor | None = None,
+        attention_mask: torch.Tensor | None = None,
+        **kwargs,
+    ) -> tuple[torch.Tensor, torch.Tensor | None]:
+        encoder_hidden_states = hidden_states if encoder_hidden_states is None else encoder_hidden_states
+
+        input_shape = hidden_states.shape[:-1]
+        hidden_shape = (*input_shape, -1, self.head_dim)
+        key_value_shape = (*encoder_hidden_states.shape[:-1], -1, self.head_dim)
+
+        query_states = self.q_proj(hidden_states).view(hidden_shape).transpose(1, 2)
+        key_states = self.k_proj(encoder_hidden_states).view(key_value_shape).transpose(1, 2)
+        value_states = self.v_proj(encoder_hidden_states).view(key_value_shape).transpose(1, 2)
+
+        attention_interface: Callable = ALL_ATTENTION_FUNCTIONS.get_interface(
+            self.config._attn_implementation, eager_attention_forward
+        )
+
+        attn_output, attn_weights = attention_interface(
+            self,
+            query_states,
+            key_states,
+            value_states,
+            attention_mask,
+            is_causal=self.is_causal,
+            scaling=self.scaling,
+            dropout=0.0 if not self.training else self.attention_dropout,
+            **kwargs,
+        )
+
+        attn_output = attn_output.reshape(*input_shape, -1).contiguous()
+        attn_output = self.o_proj(attn_output)
+
+        return attn_output, attn_weights

+class ClefEvidenceLayer(GradientCheckpointingLayer):
+    """Pre-norm cross-attention to the memory, which has a norm of its own, then a pre-norm MLP."""
+
+    def __init__(self, config: ClefConfig):
+        super().__init__()
+        self.input_layernorm = nn.LayerNorm(config.hidden_size)
+        self.memory_layernorm = nn.LayerNorm(config.hidden_size)
+        self.cross_attn = ClefAttention(config)
+        self.post_attention_layernorm = nn.LayerNorm(config.hidden_size)
+        self.mlp = ClefMLP(config)
+
+    def forward(
+        self,
+        hidden_states: torch.Tensor,
+        encoder_hidden_states: torch.Tensor,
+        **kwargs: Unpack[TransformersKwargs],
+    ) -> torch.Tensor:
+        residual = hidden_states
+        hidden_states, _ = self.cross_attn(
+            self.input_layernorm(hidden_states), self.memory_layernorm(encoder_hidden_states), **kwargs
+        )
+        hidden_states = residual + hidden_states
+
+        residual = hidden_states
+        hidden_states = self.mlp(self.post_attention_layernorm(hidden_states))
+        return residual + hidden_states

+class ClefDecoderLayer(GradientCheckpointingLayer):
+    def __init__(self, config: ClefConfig):
+        super().__init__()
+        # Not causal: the questions attend to each other
+        self.self_attn = ClefAttention(config)
+        self.encoder_attn = ClefAttention(config)
+        self.mlp = ClefMLP(config)
+        self.input_layernorm = nn.LayerNorm(config.hidden_size)
+        self.post_attention_layernorm = nn.LayerNorm(config.hidden_size)
+        self.final_layernorm = nn.LayerNorm(config.hidden_size)
+
+    def forward(
+        self,
+        hidden_states: torch.Tensor,
+        attention_mask: torch.Tensor | None = None,
+        encoder_hidden_states: torch.Tensor | None = None,
+        encoder_attention_mask: torch.Tensor | None = None,
+        position_ids: torch.LongTensor | None = None,
+        encoder_position_ids: torch.LongTensor | None = None,
+        past_key_values: Cache | None = None,
+        **kwargs: Unpack[TransformersKwargs],
+    ) -> tuple[torch.FloatTensor, tuple[torch.FloatTensor, torch.FloatTensor] | None]:
+        residual = hidden_states
+        hidden_states = self.input_layernorm(hidden_states)
+
+        hidden_states, _ = self.self_attn(
+            hidden_states=hidden_states,
+            attention_mask=attention_mask,
+            position_ids=position_ids,
+            past_key_values=past_key_values,
+            **kwargs,
+        )
+        hidden_states = residual + hidden_states
+
+        if encoder_hidden_states is not None:
+            residual = hidden_states
+            hidden_states = self.post_attention_layernorm(hidden_states)
+            hidden_states, _ = self.encoder_attn(
+                hidden_states=hidden_states,
+                encoder_hidden_states=encoder_hidden_states,
+                attention_mask=encoder_attention_mask,
+                past_key_values=past_key_values,
+            )
+            hidden_states = residual + hidden_states
+
+        residual = hidden_states
+        hidden_states = self.final_layernorm(hidden_states)
+        hidden_states = self.mlp(hidden_states)
+        hidden_states = residual + hidden_states
+        return hidden_states

+class ClefEmbeddings(nn.Module):
+    """
+    The memory of the prompt, the options, the fields of the questions with their embeddings, and the lexical prior of
+    the options, from the hidden states of the backbone and the output embeddings of the tokens of the marked spans,
+    averaged over each span.
+    """
+
+    def __init__(self, config: ClefConfig):
+        super().__init__()
+        backbone_hidden_size, hidden_size = config.backbone_hidden_size, config.hidden_size
+        self.hidden_norm = nn.LayerNorm(backbone_hidden_size)
+        self.memory_projection = nn.Linear(backbone_hidden_size, hidden_size, bias=False)
+        self.question_projection = nn.Linear(backbone_hidden_size, hidden_size, bias=False)
+        self.option_question_projection = nn.Linear(backbone_hidden_size, hidden_size, bias=False)
+        self.global_projection = nn.Linear(backbone_hidden_size, hidden_size, bias=False)
+        self.option_context_projection = nn.Linear(backbone_hidden_size, hidden_size, bias=False)
+        self.option_lexical_projection = nn.Linear(backbone_hidden_size, hidden_size, bias=False)
+        self.type_embedding = nn.Embedding(len(config.question_types), hidden_size)
+
+    def forward(
+        self,
+        hidden_states: torch.Tensor,
+        input_ids: torch.LongTensor,
+        marks: torch.LongTensor,
+        num_options: torch.LongTensor,
+        question_type_ids: torch.LongTensor,
+        output_embeddings: torch.Tensor,
+    ) -> tuple[torch.Tensor, torch.Tensor, tuple[torch.Tensor, torch.Tensor], torch.Tensor]:
+        dtype = hidden_states.dtype
+        # Each question marks the span of its instruction, then of each of its options
+        spans_per_question = num_options + 1
+        instructions = spans_per_question.cumsum(0) - spans_per_question
+        is_option = torch.ones_like(marks[::2], dtype=torch.bool).index_fill(0, instructions, False)
+        # The marks cut the prompt into segments, every other one is a span
+        boundaries = torch.cat([marks.new_zeros(1), marks, marks.new_full((1,), input_ids.shape[-1])])
+        segment_sizes = boundaries.diff().tolist()
+
+        hidden_states = self.hidden_norm(hidden_states)
+        span_states = [segment.float().mean(1) for segment in torch.split(hidden_states, segment_sizes, dim=1)[1::2]]
+        span_lexical = [
+            output_embeddings[segment].float().mean(1)
+            for segment in torch.split(input_ids, segment_sizes, dim=1)[1::2]
+        ]
+        span_states, span_lexical = torch.stack(span_states, dim=1), torch.stack(span_lexical, dim=1)
+        questions, contexts = span_states[:, instructions].to(dtype), span_states[:, is_option].to(dtype)
+        lexical = span_lexical[:, is_option].to(dtype)
+        global_state = hidden_states[:, -1:]
+        options = (
+            self.option_context_projection(contexts)
+            + self.option_lexical_projection(lexical)
+            + self.option_question_projection(questions).repeat_interleave(num_options, dim=1)
+        )
+        # The cosine of the output embeddings of each option with its question and the end of the prompt
+        anchors = nn.functional.normalize(questions + global_state, dim=-1).repeat_interleave(num_options, dim=1)
+        priors = (nn.functional.normalize(lexical, dim=-1) * anchors).sum(-1)
+        fields = self.question_projection(questions)
+        field_embeddings = self.global_projection(global_state) + self.type_embedding(question_type_ids)
+        return self.memory_projection(hidden_states), options, (fields, field_embeddings), priors
+

+class ClefEncoder(nn.Module):
+    """
+    The options attend to the prompt, each question summarizes its options into its field, then the fields attend to
+    each other and to the prompt.
+    """
+
+    def __init__(self, config: ClefConfig):
+        super().__init__()
+        self.evidence_layers = nn.ModuleList(ClefEvidenceLayer(config) for _ in range(config.num_evidence_layers))
+        self.option_summary_norm = nn.LayerNorm(config.hidden_size)
+        self.layers = nn.ModuleList(ClefDecoderLayer(config) for _ in range(config.num_hidden_layers))
+        self.field_norm = nn.LayerNorm(config.hidden_size)
+
+    def forward(
+        self,
+        memory: torch.Tensor,
+        options: torch.Tensor,
+        fields: tuple[torch.Tensor, torch.Tensor],
+        option_question_ids: torch.Tensor,
+        **kwargs: Unpack[TransformersKwargs],
+    ) -> tuple[torch.Tensor, torch.Tensor]:
+        """`fields` are the projected questions, which route the options, and the embeddings added to them after."""
+        fields, field_embeddings = fields
+        for layer in self.evidence_layers:
+            options = layer(options, memory, **kwargs)
+
+        # Each question summarizes its options, weighted by their similarity with its field (a product rather than a
+        # matmul, which rounds differently in half precision)
+        routing_logits = (fields[:, :, None] * options[:, None]).sum(-1) / math.sqrt(fields.shape[-1])
+        is_other_option = nn.functional.one_hot(option_question_ids, fields.shape[1]).T == 0
+        routing_logits[:, is_other_option] = torch.finfo(fields.dtype).min
+        summaries = routing_logits.softmax(-1, dtype=torch.float32) @ options.float()
+        fields = fields + self.option_summary_norm(summaries.to(fields.dtype)) + field_embeddings
+        for layer in self.layers:
+            fields = layer(fields, encoder_hidden_states=memory, **kwargs)
+        return options, self.field_norm(fields)
+
+
+class ClefScorer(nn.Module):
+    """Scores each option against the field of its question, on top of its lexical prior."""
+
+    def __init__(self, config: ClefConfig):
+        super().__init__()
+        self.option_norm = nn.LayerNorm(config.hidden_size)
+        self.residual_scorer = ClefResidualScorer(config)
+        self.prior_logit_scale = nn.Parameter(torch.zeros(()))
+        self.joint_logit_scale = nn.Parameter(torch.zeros(()))
+        self.residual_gate = nn.Parameter(torch.zeros(()))
+
+    def forward(self, fields: torch.Tensor, options: torch.Tensor, priors: torch.Tensor) -> torch.Tensor:
+        prior_scale = self.prior_logit_scale.clamp(max=math.log(100.0)).exp()
+        joint_scale = self.joint_logit_scale.clamp(max=math.log(100.0)).exp()
+        options = self.option_norm(options)
+        features = torch.cat([fields, options, fields * options, (fields - options).abs()], dim=-1)
+        joint = (
+            joint_scale * nn.functional.cosine_similarity(fields, options, dim=-1)
+            + self.residual_scorer(features)[..., 0]
+        )
+        return prior_scale * priors + torch.sigmoid(self.residual_gate) * joint
+

+class ClefEvidenceLayer(GradientCheckpointingLayer):
+    """Pre-norm cross-attention to the memory, which has a norm of its own, then a pre-norm MLP."""

+    def __init__(self, config: ClefConfig):
+        super().__init__()

+        self.memory_layernorm = nn.LayerNorm(config.hidden_size)
+        self.cross_attn = ClefAttention(config)
+        self.post_attention_layernorm = nn.LayerNorm(config.hidden_size)
+        self.mlp = ClefMLP(config)
+
+    def forward(
+        self,
+        hidden_states: torch.Tensor,
+        encoder_hidden_states: torch.Tensor,
+        **kwargs: Unpack[TransformersKwargs],
+    ) -> torch.Tensor:
+        residual = hidden_states
+        hidden_states, _ = self.cross_attn(
+            self.input_layernorm(hidden_states), self.memory_layernorm(encoder_hidden_states), **kwargs
+        )
+        hidden_states = residual + hidden_states

+class JevPreTrainedModel(PreTrainedModel):
+    config: JevConfig
+    base_model_prefix = "backbone"
+
+
+@auto_docstring(
+    custom_intro="""
+    Decision head of JEV (autotrust/JEV-9B): linear scores of single-token labels at the token before the `<|mark|>` of
+    each question, soft-capped like the logits of a language model head.
+    """
+)
+class JevDecisionHead(JevPreTrainedModel):
+    def __init__(self, config: JevConfig):
+        super().__init__(config)
+        self.proj = nn.Linear(config.hidden_size, config.num_verbalizers)
+        self.backbone = AutoModel.from_config(config.backbone_config)
+        self.post_init()
+
+    @auto_docstring
+    def forward(
+        self,
+        input_ids: torch.LongTensor,
+        marks: torch.LongTensor,
+        num_options: torch.LongTensor,
+        question_type_ids: torch.LongTensor,
+        backbone_kwargs: dict | None = None,
+        **kwargs,
+    ) -> torch.Tensor:
+        outputs = self.backbone(input_ids=input_ids[None], use_cache=False, **(backbone_kwargs or {}))
+        hidden_states = outputs.last_hidden_state[0]
+        logits = self.proj(hidden_states[marks - 1].to(self.proj.weight.dtype))
+        if self.config.softcap is not None:
+            logits = self.config.softcap * torch.tanh(logits / self.config.softcap)
+        # The options of a question are scored by the rows from the offset of its type on, in order
+        offsets = [self.config.offsets[question_type] for question_type in self.config.question_types]
+        starts = torch.tensor(offsets, device=logits.device)[question_type_ids]
+        rows = torch.arange(logits.shape[-1], device=logits.device)
+        return logits[(rows >= starts[:, None]) & (rows < (starts + num_options)[:, None])]

+        self.dense = nn.Linear(config.hidden_size, config.hidden_size // 2)
+        self.norm = nn.LayerNorm(config.hidden_size // 2)

+    def split_marks(self, marks: torch.LongTensor, num_options: torch.LongTensor) -> tuple[torch.Tensor, torch.Tensor]:
+        """The `[MASK]` positions `(blocks, options)` and the end of each block, for the one question of the prompt."""
+        marks = marks.view(-1, int(num_options[0]) + 1)
+        return marks[:, :-1] - 1, marks[:, -1].contiguous()
+
+    def backbone_inputs(
+        self, input_ids: torch.LongTensor, marks: torch.LongTensor, num_options: torch.LongTensor
+    ) -> dict[str, Any]:
+        """
+        Blocks are mutually invisible, options attend to the prompt of their block and to themselves, and the positions of
+        every option restart after the prompt, also for the sliding window. The masking API makes the masks for the
+        attention implementation of the backbone.
+        """
+        reads, ends = self.split_marks(marks, num_options)
+        # The state written after the last block is not part of the input
+        positions = torch.arange(int(ends[-1]), device=marks.device)
+        block_ids = torch.searchsorted(ends, positions, right=True)
+        block_reads = reads[block_ids]
+        # The option of each token is the last `[MASK]` before it, the prompt (-1) before the first one and at the end
+        option_ids = (block_reads <= positions[:, None]).sum(-1) - 1
+        option_ids = option_ids.masked_fill(positions == ends[block_ids] - 1, -1)
+        # Positions restart at each block, and every option starts where the first one does
+        option_starts = block_reads.gather(1, option_ids.clamp(min=0)[:, None])[:, 0]
+        block_starts = torch.cat([ends.new_zeros(1), ends[:-1]])[block_ids]
+        position_ids = positions - block_starts - (option_starts - block_reads[:, 0])
+

+            packed_sequence_mask_function(block_ids),
+            or_masks(packed_sequence_mask_function(option_ids), padding_mask_function(option_ids == -1)),
+        )

+

+        attention_mask = {

+            "sliding_attention": create_bidirectional_mask(
+                **mask_kwargs, and_mask_function=and_masks(options, sliding_window)
+            ),
+        }

+                "`eager` or `flex_attention`."
+            )
+        return {"inputs_embeds": inputs_embeds, "position_ids": position_ids, "attention_mask": attention_mask}

+        hidden_states = self.backbone(**backbone_inputs, use_cache=False).last_hidden_state[0].to(self.dtype)

+        logits = self.out_proj(self.norm(nn.functional.gelu(self.dense(hidden_states))))[..., 0]

+@add_end_docstrings(build_pipeline_init_args(has_tokenizer=True))
+class DecisionPipeline(Pipeline):
+    """
+    Decision pipeline: answers typed questions (`choice`, `score`, `noul`) about a `state` with a probability for every
+    option, from one forward pass per prompt (the System One API of Jev-like models). The decision config (see
+    [`DecisionConfig`]) lives next to the model or in the repo given as `decision_config`. The model can be a decision
+    head, which reads the model of its `backbone_config`; otherwise the options are scored by the next-token logits of
+    their labels, so any chat model can answer.
+
+    Example:
+
+    ```python
+    >>> from transformers import pipeline
+
+    >>> decide = pipeline("decision", model="Qwen/Qwen2.5-0.5B-Instruct")
+    >>> answers = decide(
+    ...     {
+    ...         "state": "I was charged twice for my order and want a refund.",
+    ...         "questions": {"refund": {"type": "noul", "instructions": "Is a refund requested?"}},
+    ...     }
+    ... )
+    >>> answers["refund"]["type"]
+    'noul'
+    >>> decide("Where is my parcel?")["refund"]["type"]  # a bare state is asked the last questions
+    'noul'
+    ```
+
+    Questions can also be set up front, with `pipeline("decision", model=..., questions={...})`.
+    """
+
+    _load_processor = None  # the processor of models that see images
+    _load_image_processor = False
+    _load_feature_extractor = False
+    _load_tokenizer = True
+
+    def __init__(
+        self,
+        *args,
+        decision_config: DecisionConfig | str | None = None,
+        questions: dict[str, Any] | None = None,
+        **kwargs,
+    ):
+        super().__init__(*args, **kwargs)
+        repo = decision_config if isinstance(decision_config, (str, Path)) else self.model.name_or_path
+        if not isinstance(decision_config, DecisionConfig):
+            try:
+                decision_config = DecisionConfig.from_pretrained(repo)
+            except OSError:
+                decision_config = DecisionConfig()
+        self.template = DecisionTemplate(self.processor or self.tokenizer, decision_config, questions)
+        self.logits_processors = {
+            kind: decision_config.get_logits_processor(kind) for kind in Question.questions_types
+        }
+
+    def _sanitize_parameters(self, questions: dict[str, Any] | None = None, assets: dict[str, Any] | None = None):
+        preprocess_params = {key: value for key, value in (("questions", questions), ("assets", assets)) if value}
+        return preprocess_params, {}, {}
+
+    def __call__(
+        self,
+        inputs: dict[str, Any] | str | list,
+        questions: dict[str, Any] | None = None,
+        assets: dict[str, Any] | None = None,
+        **kwargs,
+    ):
+        """
+        Answer the questions of one or several System One requests.
+
+        Args:
+            inputs (`dict`, `str` or `list`):
+                `{"state": ..., "questions": {name: {"type": ..., "instructions": ..., "criteria": ...}}}` or its JSON,
+                with `type` one of `choice` (`criteria` maps options to descriptions), `score` (`criteria` lists the
+                levels, lowest first) or `noul` (optional `criteria` describe `true` and `false`). Any other input is
+                a bare `state`, asked the current questions: those of the last request, or the ones set up front.
+                Requests can carry `assets`, as in the System One API.
+            questions (`dict`, *optional*):
+                Questions to ask the input, as a bare `state`. They become the current questions.
+            assets (`dict`, *optional*):
+                Images keyed by a placeholder: wherever the placeholder appears in a string of the state, the
+                instructions or the criteria, the model sees the image. An image is a System One asset (`{"type":
+                "image", "format": "png", "data_base64": ...}`), a PIL image, a path or a URL. Needs a model with a
+                processor that handles images.
+
+        Return:
+            `dict` (or a list of `dict`): The answers keyed by question name, in the System One format.
+        """
+        return super().__call__(inputs, questions=questions, assets=assets, **kwargs)
+
+    def preprocess(self, inputs, questions: dict[str, Any] | None = None, assets: dict[str, Any] | None = None):
+        prompts = self.template(inputs if questions is None else {"state": inputs, "questions": questions}, assets)
+        return {
+            "prompts": prompts,
+            "inputs": [prompt.model_inputs() for prompt in prompts],
+            "backbone": [prompt.backbone_inputs() for prompt in prompts],
+        }
+
+    def _forward(self, model_inputs):
+        # TODO: batch / continious batching
+        scores = []
+        for prompt, inputs, backbone in zip(model_inputs["prompts"], model_inputs["inputs"], model_inputs["backbone"]):
+            if hasattr(self.model.config, "backbone_config"):  # a decision head, on the model it reads
+                backbone_kwargs = {key: value for key, value in backbone.items() if key != "input_ids"}
+                option_scores = self.model(**inputs, backbone_kwargs=backbone_kwargs)
+                scores.append(option_scores.split(inputs["num_options"].tolist()))
+            else:  # the logits of the labels before each mark
+                logits = self.model(**backbone, use_cache=False, logits_to_keep=inputs["marks"] - 1).logits[0]
+                labels = [label_token_ids(self.tokenizer, question) for question in prompt.questions]
+                scores.append([logits[index, label_ids] for index, label_ids in enumerate(labels)])
+        return {"prompts": model_inputs["prompts"], "scores": scores}
+
+    def postprocess(self, model_outputs):
+        answers = {}
+        for prompt, prompt_scores in zip(model_outputs["prompts"], model_outputs["scores"]):
+            # the tokens after the last mark, where the template writes the state
+            input_ids = torch.tensor(prompt.input_ids[prompt.marks[-1] :])
+            for question, scores in zip(prompt.questions, prompt_scores):
+                scores = self.logits_processors[question.type](input_ids, scores.float())
+                answers[question.name] = question.answer(scores.softmax(-1).tolist())
+        return answers
