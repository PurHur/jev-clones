# Jev clone discovery (2026-10-19)

Scope: every open replication, "Jev clone", Jev-inspired or System-One-compatible decision model that exists as of
2026-10-19. Jev = TypeSafe's hosted System One model (`POST /v1/systemone`, question types `noul` / `choice` /
`score`, one forward pass, no text generation; launched 2026-09-15, current `jev-1.14.0` per Decision Index 0.3.2).

All facts below come from the GitHub API, the Hugging Face API, model cards / READMEs, or the curated lists named in
"Sources". Architecture lines are what each project says about itself (or what a curated list says). They were
not re-verified by running anything. No downloaded code was executed. "?" means not verified.

## Summary

* **The space is far bigger than the four clones in the brief.** In 34 days the ecosystem produced:
  * ~**1,320 Hugging Face model repos** created on/after 2026-09-14 that carry Jev / System One / typed-decision
    signals in name, tags or card (quant-only repos excluded). Breakdown: 440 belong to the ~190 families in Table A,
    189 are fine-tunes of an existing clone (68 of Laya, 30 of Laya-multilingual, 36 of Clef/Clef-flash/Clef-omni, 13 of
    Decider, 8 of Kev...), 686 are a long tail of independent small projects. Full list:
    `notes/hf_candidates.tsv`.
  * ~**2,200 GitHub repos** created since 2026-09-14 that match Jev / System One / decision-model searches. Most are
    apps on hosted Jev. 677 model-ish ones were inspected; 211 link their own weights (`notes/github_candidates.tsv`).
  * The Decision Index (multimodalart HF Space) benchmarks **173 entries** (`notes/decision_index_0.3.2_entries.tsv`).
* **Big-lab open weights now exist and outscore the small clones**: Cloudflare Clef (27B, 9B, 30B-A3B omni),
  Perplexity pplx-decider (27B, 4B flash), vLLM Semantic Router Decision 1.0/2.0/3.0 (0.6B-27B), Liquid AI d1
  (3B, 600M), InternLM Intern-Decision (0.8B-4B), Together Tev1 (4B, 0.8B), H2O-Lightning-4B, AWS Strands Decider
  (2B, later Gemma 4 sizes), Bespoke Nimble 9B, Fastino GLiNER2.5-Decide, StartLux, Nace.AI Drex, Juspay Xor, etc.
* **Most-downloaded clone family is AutoTrust "JEV-*"** (JEV-27B-VL ~1.93M downloads, 7.9k likes; family ~4.4M):
  students distilled directly from Jev 1.13 outputs (dataset `SargeDev/jev-distill-corpus-v3`).
* **Architectures cluster into five patterns** (useful for the comparison phase):
  1. decoder LLM (Qwen3.5/3.8, Gemma 4, Ministral, MiniCPM) + LoRA + **pointer / scalar / joint head** over option
     markers (Kev, Strands Decider, Jeeves, Open-Jev, Clef "joint head", Valen MLP-Mixer head, Zeiger, train-jev
     24-slot head, OpenThai 256-way slot head);
  2. decoder LLM fine-tuned to emit **one option letter/label token**, probabilities read from logits (Tev1, JevK5,
     Jev-Style, Vev, Rizzo Flow, PlayJev, Dwight, gutsy);
  3. **bidirectional encoder** + decision head (Laya ModernBERT/mmBERT, Von, Verdict, Julia-1, Phocinae, Decima,
     Crivo, Bekko, MayaZ, GLiNER2.5-Decide, FRIDA-Decisions, sokudan, OpenDecider-nano on Ettin);
  4. **training-free readout** from frozen LLMs or diffusion LMs (SemIf, AnyJev, simple-jev, DiffusionGemma servers,
     LocalJev) -> Table B, not models;
  5. **contrastive / embedding** decision models (CLM-v0.1-8B, JevEmbed, embeddinggemma-2 typed decision).
* **browser-use/jev-ultrafast is a harness, not a model** (confirmed from README): a browser agent loop that sends
  one request per step to hosted TypeSafe Jev to pick an operation and target element, plus a small LLM for typing.
  Its derivative `ipenywis/laya-ultrafast` swaps in Laya; `lexmount/WebJev` trains a 35B-A3B model for that loop.
* **Forks of kev (627) and laya (3,007)** are almost all plain forks. Notable divergent ones: AyushChauhan9389/kev
  (MiniCPM5 base support), SPhillips1337/kev (low-end GPU), tonychang04/laya-template (CPU API), joaoajmatos/laya-sparse
  (sparse attention >2K tokens), r33drichards/laya-vision (SmolVLM image input; has weights), stickleetoto/laya (Korean),
  DrGekoz/Laya-for-Agents.
* **Newest model clones (created 2026-10-12..19)**: AutoTrust-JEV-27B v1.1 (10-17), pplx-decider-v1.2 + flash-v1.2
  (10-15), Matilda Decision (10-15), OneJev 1.5 (10-12/13), Sieve-0.8B/31B (10-12), Amos-1 (10-12), Lev looped
  (OpenLAIR, 10-14), Turnike-JEV EN/TR (10-13/14), nari-decision-4b KO/EN (10-14), Bonsai-JEV (10-14), CJRouter Clef
  replications (10-13), Dwight-4B (10-13), SPEV (10-13), MayaZ 17-68M (10-13), Chon 1.0 (10-14), ActionMan-0.1 (10-15),
  CoCo-Decision-2.4 (10-15), MISA AI 2.0 Decision Plus (10-16), train-jev 24-slot head (10-16), soro-kev (10-17),
  rycerzes/Qwen3.5-2B-Decision (10-17), Tern-35B-A3B (10-18), mentat-sys1 v0.3 (10-18), Elythros decider (10-18),
  kartikg1/tevro-decider (10-18), TeenageWorks Toddler-Jev audio (10-18), sp1d5r/video-jev (10-18).
* **Hygiene flag**: ~25 GitHub repos with the identical description of `kouhxp/gutsy` were created by unrelated
  accounts 2026-10-14..19 (e.g. aSanchez60/gutsy, ElenaPerez49358/gutsy). Pattern looks like spam/possible
  malware re-uploads; do not clone those, use only `kouhxp/gutsy`.

  options of all questions; Apache-2.0; ties Jev in the Sj0605 common-ground benchmark (Clef-flash 83.1, Jev 83.0, Clef 83.0 %). CJRouter has

## Dead ends and caveats

* "Jev's Architecture Unmasked" (archerhume.com, cited by kev) is not indexed by web search; not fetched.
* X/Twitter not directly searchable; only tweets linked from HN were seen (CUA-S1 by trycua, CLM by jackyk02,
  THX-01 by reversedoofz, RTX 3070 System One by lafalcemateo). trycua "CUA-S1" family: only `cua-ai/cua-s1-forms`
  found on HF (0 downloads).
* Reddit: only reached through mirrors (redlib, prismix.dev); Qwen "decision-model-preview" claim is docs-only.
* HF anonymous API rate-limited after ~600 calls; all 1,597 ids were refetched slowly; 16 still failed
  (`FETCHFAIL` rows in hf_analysis, mostly deleted/renamed repos).
* `gh search code` with several quoted terms returns nothing; code search was therefore not useful.
* HF `search=` is substring-based (`kev` and `laya` hit 1,000 unrelated repos); relevance was decided by keyword
  score over id + tags + card, and creation date >= 2026-09-14. Pre-launch models that later re-branded
  (e.g. GLiNER2 base, NeoHorse-1 base) may be under-counted.
* "OpenJev", "Jeff", "Lev", "Bev", "Verdict", "Reflex", "Deem", "Decider" are each used by 2-6 unrelated projects.
* Downloads for some repos are hidden/zero (gated or untracked); "most popular" rankings are approximate.
* Stars on several ecosystem repos are implausibly high for their age; the ~25 gutsy copies suggest some
  GitHub spam activity around this topic.
* Nothing was cloned into `sources/` for this discovery pass (READMEs read via API only); nothing was executed.
